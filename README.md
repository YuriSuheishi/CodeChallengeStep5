## Description
This project is a simple webpage built using HTML and CSS, developed as part of a code challenge. The primary goal was to replicate the design provided in a Figma file as accurately as possible, focusing on layout, styling, and responsiveness.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YuriSuheishi/CodeChallengeStep5.git
   ```
2. Navigate to the project folder:
   ```bash
   cd CodeChallengeStep5
   ```
3. Open `index.html` in your preferred browser to view the project.
